# Guided mode

For a user whose AI has no browser tool (for example ChatGPT Free). The user clicks; you direct and check.

- **One step per message.** Each message names one place to click or one field to fill, by its Georgian label exactly as it appears on the page, and ends by asking for a screenshot.
- **Check each screenshot** against what the step should have produced before giving the next step. When it differs, say what you see and give the correcting step.
- **Rights**: give the module title and the exact checkbox labels to tick (from [`rights-presets.md`](rights-presets.md)), then ask for a screenshot of that module block. Clear all first with **მონიშნულების გასუფთავება**.
- **The summary** (step 5) is built from the screenshots, not from what you asked for.
- **Password**: the password step is last. Ask for no screenshot after the password is typed. Ask instead for a screenshot of the list after Save, and of the rights in the **ცვლილება** view (its password field opens empty).
- Before any screenshot, remind the user that it should show only the rs.ge form or list: no other tabs, messages or passwords.
